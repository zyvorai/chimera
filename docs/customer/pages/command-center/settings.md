# Settings

## Purpose

Show listen address and change Command Center admin username/password live (no restart).

## When to use it

After first login in any shared lab; before exposing Chimera beyond localhost.

## How to get there

Dashboard Settings panel (operator chrome).

## What you can do

- Review listen / endpoint info
- Rotate admin credentials used by the UI login gate
