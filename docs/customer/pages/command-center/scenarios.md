# Scenario Launcher

## Purpose

One-click deterministic presets for clean, slow, flaky, and resume export paths.

## When to use it

Repeatable Transiva / client tests without hand-tuning Fault Studio each time.

## How to get there

Overview — scenario cards.

## What you can do

- **Clean Environment** — baseline happy path
- **Slow Fabric** — latency pressure
- **Flaky API** — intermittent failures
- **Resume Export** — NFC drop for Range/206 retry
