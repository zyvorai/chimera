# VMDK Library

## Purpose

List and manage `.vmdk` fixtures under configured fixture directories; upload or browse; optionally pin to a VM.

## When to use it

Testing Transiva **conversion** with real disks, not only NFC transfer of synthetic fixtures.

## How to get there

Overview — VMDK Library card.

## What you can do

- Upload a `.vmdk` into `fixture_vmdk_dir`
- Browse staged host files under fixture roots only
- Pin/clear Manual assignment (overrides name/round-robin matching)
- Auto re-scan every ~5 seconds
