# Topology

## Purpose

Visual datacenter → cluster → host → datastore map of the simulated estate.

## When to use it

Orient operators to inventory shape before export tests.

## How to get there

Overview board — topology panel. Use **View Full Topology** for full-viewport zoom (`Fit` / `+`).

## What you can do

- Inspect labels hydrated from config counts and fixture size
- Dismiss overlay via button, outside click, or Escape
